# MacStore Releases

Downloads for **[MacStore](https://macstore-inky.vercel.app)**: free, native macOS solutions for everyday problems. Each one is a small Swift app for **macOS 14 Sonoma or later** (Apple silicon & Intel), signed with a Developer ID and **notarized by Apple**, with no account.

| Solution | The problem it solves | Download |
|---|---|---|
| **[Storage Buddy](https://macstore-inky.vercel.app/storage-buddy)**: free Mac disk space analyzer and cleaner | "My Mac is running out of space and I don't know what's filling it." | [Latest DMG](https://github.com/wrteamJignesh/MacStore-Releases/releases?q=storage-buddy) |
| **[ClipVault](https://macstore-inky.vercel.app/clipvault)**: free clipboard manager and history for Mac | "I copied something an hour ago and now it's gone." | [Latest DMG](https://github.com/wrteamJignesh/MacStore-Releases/releases?q=clipvault) |

## Install

1. Download the DMG for the solution you need.
2. Open it and drag the app to **Applications**.
3. Open the app. It's notarized, so macOS opens it like any other Mac app.

Details, screenshots and FAQs for each solution: **https://macstore-inky.vercel.app**
